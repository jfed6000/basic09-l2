@category Help

== Help | basic09-l2 help
Help for the basic09-l2 editor and the Basic09 language.

  {Editor keys|Keys}    moving, editing, files, Make and Run
  {Menus}          every menu command
  {Statements}     PRINT, FOR, DIM, TYPE, RUN ...
  {Functions}      LEFT$, SIZE, ADDR, SIN ...
  {Errors}         what the error numbers mean
  {Index}          every topic

Left/Right selects a link, Enter follows the link.
Up/Down scrolls a long page.
Backspace returns to the prior page.
F1 for this page.  F2 for the searchable {Index} (type a name to search).
Esc or Run/Stop returns to the editor.

F1 with the cursor on a keyword in the editor displays that keyword's
help.
